01 / COMPUTATIONAL ASTRODYNAMICS

Orbital Mechanics Simulation.

A MATLAB-based study of spacecraft trajectory propagation, comparing ideal two-body motion with the influence of Earth's oblateness through the J₂ perturbation model.

MATLABNUMERICAL INTEGRATIONORBITAL DYNAMICS

Project overview

This project applies classical astrodynamics to model the time evolution of a spacecraft state. The simulation is structured around numerical integration of the equations of motion, with a baseline two-body model and an extended model that includes the dominant J₂ term in Earth's gravity field.

GOVERNING EQUATIONS

ṙ = v     v̇ = −μ r / |r|³ + aJ₂

The two-body acceleration provides the central-gravity baseline. The perturbing acceleration accounts for the first-order effect of Earth's equatorial bulge.

Technical approach

  • Represent the spacecraft state using position and velocity components in an inertial coordinate frame.
  • Implement the equations of motion as a numerical derivative function for an ODE solver.
  • Propagate the baseline two-body trajectory and the perturbed trajectory over a common time span.
  • Compare orbital element behavior and secular changes to analytical expectations for J₂ perturbations.
  • Visualize the trajectory and inspect the evolution of orbital parameters.

Engineering concepts

Two-body orbital mechanics, numerical integration, coordinate systems, classical orbital elements, perturbation theory, and validation against analytical secular-rate relationships.

What I am developing

The main value of this work is connecting the physical model to its numerical implementation: selecting state variables, building a consistent derivative function, checking units and coordinate conventions, and validating numerical trends against theory.

Portfolio update: add final trajectory plots, the exact initial conditions, solver settings, and selected MATLAB source files before presenting quantitative results.

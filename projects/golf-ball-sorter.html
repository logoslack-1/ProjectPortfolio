Automated Golf Ball Sorter.

Designed, built, and programmed a machine that detects golf ball arrival, classifies ball color in real time, and redirects each ball into a designated output basket.

ARDUINO UNOTCS3200 RGB SENSORIR DETECTIONSERVO ACTUATION

Project overview

The system combines an infrared sensing stage, a color-frequency sensor, embedded control logic, and mechanical redirection. An IR sensor detects the incoming ball. A TCS3200 color sensor provides the RGB-related readings used for classification. The Arduino Uno processes the measurements and commands high-torque digital servos to route the ball through the mechanism and into one of three collection baskets.

SYSTEM SEQUENCE

Ball arrival detection → color-frequency measurement → RGB classification → servo / pneumatic redirection → collection in the selected output basket.

CAD and completed hardware

The design was modeled in SolidWorks before fabrication. The CAD concept lays out the enclosure, internal sensing and actuation hardware, and the external ball-routing paths. The completed build brings those elements together in a compact wood enclosure with PVC routing components and three collection baskets.

Controls and hardware

  • Controller: Arduino Uno.
  • Object detection: TCRT5000 infrared sensors.
  • Color classification: TCS3200 color-frequency sensor.
  • Actuation: MG996R high-torque digital servos, coordinated through programmed control logic.
  • Mechanical routing: 2-inch PVC pipe sections, a fabricated enclosure, and three collection baskets.

Engineering considerations

The project required coordinating sensor acquisition with mechanical timing so that the ball reaches the correct redirection point after it has been identified. Practical design considerations include sensor positioning, repeatable color readings, servo response, ball clearance, mechanical alignment, and reliable power delivery to the actuators.

The completed project was designed to provide repeatable sorting into designated output channels. The build sheet describes the machine as capable of real-time color detection and pneumatic / servo redirection.
